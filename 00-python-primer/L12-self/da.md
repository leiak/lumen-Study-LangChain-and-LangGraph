## 📋 卡片5：常用操作速记（背这个就够了）

```python
# ─── 列表（最常用）─────────────────────────────────
.append()   .pop()    .insert()   .remove()  # 增删
.sort()     .reverse()                        # 排序
len(lst)    lst[0]    lst[-1]    lst[1:3]    # 查

# ─── 字典（第二常用）─────────────────────────────
d["key"] = val    # 增/改
del d["key"]      # 删
d.get("key", 默认) # 安全查
d.keys()  d.values()  d.items()  # 遍历

# ─── 集合（去重神器）─────────────────────────────
s.add(4)     s.remove(3)    # 增删
s1 & s2      # 交集
s1 | s2      # 并集  
s1 - s2      # 差集
len(s)       # 去重后个数

# ─── 元组（最省心）─────────────────────────────────
t = (1, 2, 3)
t[0]         # 只能查，不能改
a, b = t     # 解包（超好用）
```
